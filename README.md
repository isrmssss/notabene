# notabene
Локальный AI-блокнот — аналог Google NotebookLM, работающий полностью на вашем компьютере. Загружайте документы, задавайте вопросы по ним, получайте ответы с опорой на загруженные материалы.
Все данные хранятся локально. Ни один файл не покидает ваш компьютер (кроме запросов к API выбранного LLM-провайдера).
## Возможности
- **Мультиформатный парсинг документов** — извлечение текста из PDF, DOCX, PPTX, CSV, EPUB, TXT, MD и изображений (14 форматов)
- **OCR** — распознавание текста на изображениях (EasyOCR, русский + английский)
- **Гибкая настройка LLM** — поддержка любых OpenAI-compatible API (OpenAI, Ollama, Groq, LM Studio, vLLM и другие)
- **Локальное хранение** — SQLite база данных, файлы на диске, никаких внешних сервисов
- **HTMX-интерфейс** — быстрый серверный рендеринг без тяжёлого фронтенда
## Поддерживаемые форматы
| Тип | Форматы |
|-----|---------|
| Документы | PDF, DOCX, PPTX, EPUB |
| Текст | TXT, MD, CSV |
| Изображения | JPG, PNG, BMP, GIF, TIFF, WebP, HEIC, AVIF, JP2, ICO |
Для PDF, DOCX и PPTX дополнительно извлекается текст из встроенных изображений через OCR.
## Быстрый старт
### Требования
- Python 3.10+
- ~2 GB свободного места (модели EasyOCR)
### Установка
```bash
git clone <url>
cd notabene
python -m venv venv
source venv/bin/activate  # Linux/macOS
# venv\Scripts\activate   # Windows
pip install -r requirements.txt
Запуск
cd notabene_project
python app.py
```

Приложение откроется по адресу http://127.0.0.1:8000
Настройка провайдера
1. Откройте настройки (иконка шестерёнки)
2. Нажмите «Добавить провайдера»
3. Укажите:
   - Название — например OpenAI, Ollama, Groq
   - API ключ — получен у провайдера (для Ollama не обязателен)
   - Base URL — endpoint API (для Ollama: http://localhost:11434/v1)
4. Добавьте модели с их кодами (например gpt-4o, llama3, mixtral-8x7b)

Стек: Python, FastAPI, SQLite, HTMX, EasyOCR, pypdf, python-docx, python-pptx
